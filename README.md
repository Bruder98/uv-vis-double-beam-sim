# 빛을 읽는 실험실 · UV–vis 이중 빔 3D

고등학교 생명과학의 광합성 색소 흡광도 분석을 위한 한국어 웹 시뮬레이션입니다.

## 실행과 배포

- `배포본/index.html`을 Chrome 또는 Edge에서 엽니다. 설치·인터넷·서버가 필요 없습니다. WebGL을 지원하는 브라우저가 필요합니다.
- `UV-vis_3D_시뮬레이션_배포.zip`을 전달하면 받는 사람은 압축을 풀고 `index.html`을 열 수 있습니다.
- URL로 공유하려면 `배포본`의 파일을 GitHub Pages·학교 서버 등 정적 웹 호스팅에 올립니다. `index.html`이 웹 루트에 오도록 배치합니다. 이번 산출물은 배포 가능한 파일이며 공개 URL은 아직 만들지 않았습니다.
- 스마트폰에서도 반응형 화면과 터치 회전을 지원합니다. 모바일에서 로컬 HTML 파일 열기가 제한되는 경우 웹 호스팅 URL로 접근합니다.
- 스캔 결과는 로컬 CSV로 저장됩니다. 개인정보나 측정 데이터를 서버로 전송하지 않습니다.
- 라이브러리 라이선스 파일을 함께 배포합니다. 학교 수업에서 자유롭게 복사·수정·배포할 수 있습니다. 이 프로젝트 코드는 동봉한 MIT 라이선스를 따릅니다.

## 학습 순서

1. **작동 원리 탐색**: 여섯 단계를 선택하며 광원 → 회절격자·슬릿 → 회전 디스크 → 큐벳 → 단일 검출기 → 계산의 연결을 관찰합니다.
2. **시료 넣고 측정하기**: 깨끗한 에탄올 Blank로 보정한 뒤 색소를 넣습니다. 기준 큐벳은 에탄올로 유지합니다.
3. 662 nm, 엽록소 a, 상대 농도 1×, 광로 길이 1 cm에서는 모형 흡광도 A ≈ 0.800, 투과율 ≈ 15.85%입니다. '예시 자동 실행'으로 같은 조건을 즉시 설정할 수 있습니다.
4. 농도를 2×로 바꾸면 A ≈ 1.600, 투과율 ≈ 2.51%입니다. 광로 길이가 바뀌면 다시 Blank를 보정합니다.
5. 380–700 nm 스캔은 1 nm 간격의 321개 모형값을 기록합니다. 그래프에서 파장을 선택하거나 CSV로 저장합니다.
6. 오염된 Blank로 보정한 뒤 550 nm에서 엽록소 a를 측정하면 A ≈ −0.085가 나옵니다. 보정 자체는 0.000으로 표시되며 시료로 바꾼 다음 음수가 나타납니다.

## 과학적 모형

- 제공된 활동지 4쪽의 **회전 디스크형 이중 빔·단일 검출기** 구조를 참고했습니다. 시료·기준·차단 구간을 시간적으로 번갈아 표시합니다. 정적인 빔 분리기에 검출기 두 개를 붙인 구조와 구분됩니다.
- 단색화 장치는 회절격자와 슬릿을 표현합니다. 가시광선 380–700 nm만 조작하며 UV 영역은 이 버전에 포함하지 않습니다.
- 검출기의 암신호를 보정한 시료 신호 S, 기준 신호 R, Blank 비율 ρᵦ = Sᵦ/Rᵦ로 계산합니다.
- T = (S/R)/ρᵦ, A = −log₁₀T. 화면의 I = S, I₀ = R·ρᵦ는 보정 후 등가 광세기입니다. I₀를 광원 자체의 출력과 혼동하지 않습니다.
- 예제는 공통 용매 투과율 0.97과 채널 불균형 0.96을 넣고 Blank로 보정합니다. 광원 세기를 바꾸면 S와 R이 함께 변하므로 A는 유지됩니다.
- 색소 곡선은 가우스 흡수대의 합으로 만든 **교육용 합성 모형**입니다. 실제 분광분석기에서 측정한 데이터나 특정 용매의 검증된 흡광계수가 아닙니다. 상대 농도에 따른 이상적 Beer–Lambert 관계를 사용합니다.
- 오염된 Blank 오류는 모든 파장에서 0.11의 추가 흡광도를 주는 단순 모형입니다. 실제 오염의 파장 의존성을 재현하지 않습니다.
- 빛의 속도, 부품 크기·배치·디스크 각도는 개념 설명용입니다. 회전 각도와 광선의 정확한 접촉 기하학을 계산하는 설계용 광선 추적기는 아닙니다. 회전 디스크의 차단 구간은 암신호를 보여 줍니다.
- 실제 장비의 셀 체인저, 미광, 산란, 형광, 포화, 노이즈, 고농도 비선형성은 구현하지 않았습니다.

## 개발과 검증

소스: `main.js`, `model.mjs`, `style.css`, `index.template.html`. 새 컴퓨터에서는 `npm install` 후 `npm run build`로 단일 HTML 배포본을 생성합니다. 현재 워크스페이스에서는 이미 설치된 인접 프로젝트의 의존성도 재사용할 수 있습니다. Vercel은 `vercel.json`에 따라 자동 빌드하고 `배포본`을 서비스합니다.

```powershell
npm install
npm test
npm run build
```

`test-model.mjs`는 Blank·농도·길이·광원 변화·음수 오류·321점의 계산을 검증합니다. 개발 워크스페이스의 `qa/check-browser.cjs`로 인터넷을 차단한 Edge에서 로컬 파일을 열고 3D, 실험 조작, 스캔·CSV, 모바일 화면을 검증했습니다. QA 이미지·임시 파일·원본 PDF는 저장소 업로드에서 제외합니다.
